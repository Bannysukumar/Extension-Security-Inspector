# Changelog

All notable user-facing changes are listed here. Versions follow [Semantic Versioning](https://semver.org/).

## 0.1.1 — 2026-09-27

Documentation update for the Marketplace listing.

### Changed

- Rewrote the install and Marketplace description so users can understand the product quickly
- Moved developer, test, and publish instructions out of the main user-facing page

## 0.1.0 — 2026-09-27

First public release.

### Added

- Local audit of installed VS Code extensions from metadata and manifests
- Security Inspector Activity Bar view with overview, attention groups, inventory, and capabilities
- Extension detail view with findings, declared capabilities, and metadata
- Search, filters, and side-by-side comparison
- Exportable Markdown, JSON, and HTML reports
- Privacy page and Workspace Trust notice
- Optional local dependency overview (off by default)

### Notes

- Findings are review indicators, not malware verdicts
- The extension does not send project files, credentials, or telemetry to external servers
